# CSS Preset Manager

A SillyTavern extension that adds preset management to the Custom CSS field in User Settings.

## Features

- **Save** your current Custom CSS as a named preset
- **Load** any saved preset from a dropdown
- **Rename** existing presets
- **Delete** presets you no longer need

## Installation

1. Open SillyTavern and go to **Extensions** → **Install Extension**
2. Paste the URL of this repository and click Install
3. Reload SillyTavern

Or manually copy this folder into `data/<user>/extensions/third-party/`.

## Usage

1. Go to **User Settings** → scroll to the **Custom CSS** section
2. A **CSS Presets** dropdown will appear above the textarea
3. Write or paste your CSS, then click **Save** to store it as a preset
4. Switch between presets using the dropdown — selecting a preset loads its CSS into the textarea
5. Use the ✏️ button to rename or the 🗑️ button to delete a preset

> **Tip:** Save your current CSS as a preset before loading a different one, since selecting a preset replaces the textarea content.
